Simplified original-circuit model: base–emitter voltage is clamped at 0.65 V when conducting; collector current = 200 × base current. Gain 200 is an assumed example, not a measured BC547 value. The LDR range is 1 kΩ–1 MΩ, not a calibrated light scale. Because the original has no LED series resistor, LED current here is set by the assumed transistor gain. Real LED brightness and current can differ substantially. Values are rounded to 0.001 µA.
